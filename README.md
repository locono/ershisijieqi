# 二十四节气 · 中国人的时间哲学

> 以太阳周年视运动为尺，将一年划分为二十四个节气。

一个精美的二十四节气主题单页网站，采用中国传统宣纸风格设计，纯原生 HTML/CSS/JavaScript 实现，零依赖。

[![PRs Welcome](https://img.shields.io/badge/PRs-welcome-brightgreen.svg)](#贡献)

## ✨ 功能特性

### 📅 节气内容
- **二十四节气详情** — 每个节气的时令、物候、农事、风俗、养生与诗词
- **七十二候** — 五天为一候，每节气三候，完整呈现古人的物候观察
- **节气诗话** — 各节气相关的经典诗词赏析
- **十二时辰** — 十二时辰对照表，含时辰名、时间区间与别称
- **文化长卷** — 历法渊源、申遗历程、物候知识、农事指南

### 🎨 设计特色
- **宣纸质感** — 传统宣纸纹理 + 颗粒质感背景
- **四季配色** — 春绿、夏红、秋金、冬蓝，应季而变
- **书法字体** — 楷体/宋体为主，排版典雅
- **印章元素** — 朱红印章点缀，古意盎然
- **响应式设计** — 完美适配桌面、平板、手机

### ⚡ 交互体验
- **二十四节气盘** — 交互式圆形节气盘，悬停预览，点击进入详情
- **今日节气** — 自动推算当前节气、进度条、下一节气倒计时
- **四时运行时间线** — 春夏秋冬四季时间线，每季六节气
- **时令粒子动效** — 春落花、夏流光、秋落叶、冬飘雪，随季节变换
- **顶部导航栏** — 平滑滚动跳转，当前模块自动高亮
- **滚动阅读进度条** — 顶部实时显示阅读进度
- **返回顶部按钮** — 滚动后显示，一键回到顶部
- **滚动显现动画** — 内容区块随滚动渐入
- **深色模式友好** — 支持系统 `prefers-reduced-motion` 偏好

## 🎯 页面结构

| 区块 | 说明 |

| **顶部导航** | 品牌标识 + 模块导航 + 当前节气胶囊 |
